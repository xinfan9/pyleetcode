<p>给定一个字符串 <code>s</code> ，请你找出其中不含有重复字符的&#xa0;<strong>最长 <span data-keyword="substring-nonempty">子串</span></strong><strong>&#xa0;</strong>的长度。</p>

<p>&#xa0;</p>

<p><strong>示例&#xa0;1:</strong></p>

<pre>
<strong>输入: </strong>s = "abcabcbb"
<strong>输出: </strong>3 
<strong>解释:</strong> 因为无重复字符的最长子串是 <span><code>"abc"</code></span>，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
</pre>

<p><strong>示例 2:</strong></p>

<pre>
<strong>输入: </strong>s = "bbbbb"
<strong>输出: </strong>1
<strong>解释: </strong>因为无重复字符的最长子串是 <span><code>"b"</code></span>，所以其长度为 1。
</pre>

<p><strong>示例 3:</strong></p>

<pre>
<strong>输入: </strong>s = "pwwkew"
<strong>输出: </strong>3
<strong>解释: </strong>因为无重复字符的最长子串是&#xa0;<span><code>"wke"</code></span>，所以其长度为 3。
&#xa0;    请注意，你的答案必须是 <strong>子串 </strong>的长度，<span><code>"pwke"</code></span>&#xa0;是一个<em>子序列，</em>不是子串。
</pre>

<p>&#xa0;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>0 &lt;= s.length &lt;= 10<sup>5</sup></code></li>
	<li><code>s</code>&#xa0;由英文字母、数字、符号和空格组成</li>
</ul>
